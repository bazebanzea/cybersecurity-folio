# Cybersecurity Folio

Portfolio web présentant mon profil et mes projets en cybersécurité (Security by Design, DevSecOps, threat modeling).

## Stack technique

- React, TypeScript, Vite
- Tailwind CSS, shadcn/ui

## Démarrage local

```bash
npm install
npm run dev
```

## Contenu

Ce portfolio référence mes projets clés :
- Système de détection d'intrusion par Machine Learning pour l'IoT (voir dépôt `Training--memoire`)
- Sentinel MFA — authentification multi-facteurs
- Secure Score Hub — tableau de bord SOC
- CERT RDC Kinshasa — plateforme de gestion d'incidents cyber
